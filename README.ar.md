# ☁️ cloud-browser — متصفح سحابي مجاني

استخدم جهاز Ubuntu الافتراضي المجاني في GitHub Actions لتشغيل سطح مكتب سحابي يمكنك الوصول إليه من متصفحك، مع متصفح Chrome مدمج. افتح صفحة ويب ويصبح لديك كمبيوتر سحابي متصل بالإنترنت — أغلقه عند الانتهاء. مجاني تمامًا.

## ✨ الميزات

- 🌐 سطح مكتب Ubuntu + متصفح Chrome، يُدار مباشرة داخل متصفحك
- ⌨️ طريقة إدخال صينية fcitx5 مدمجة (بينيين)، للتبديل بين الصينية/الإنجليزية بـ `Ctrl+Space`
- 📋 النص الصيني المنسوخ على هاتفك يمكن لصقه مباشرة في سطح المكتب البعيد
- 🖱️ قائمة النقر الأيمن على سطح المكتب لتبديل طريقة الإدخال أو إعادة تشغيل Chrome بنقرة واحدة
- 🌐 الوصول عبر نفق Cloudflare — لا حاجة لعنوان IP عام ولا لإعادة توجيه المنافذ
- 🖱️ الاتصال من الهاتف أو اللوحي أو الحاسوب (عميل noVNC الويبي)
- ⏱️ كل جلسة تعمل حتى ~6 ساعات، ويمكنك الإلغاء في أي وقت

## 🚀 طريقة الاستخدام (انسخ وانطلق)

### الخطوة 1: انسخ (Fork) هذا المشروع

انقر زر **Fork** في الزاوية العلوية اليمنى من هذه الصفحة لنسخ المشروع إلى حساب GitHub الخاص بك. بعد النسخ ستنتقل إلى مستودع `your-username/cloud-browser`.

> 💡 لماذا النسخ؟ لا يمكن لـ GitHub Actions أن يعمل إلا على المستودعات التابعة لحسابك — النسخ يمنحك صلاحية بدء التشغيل.

### الخطوة 2: شغّل المتصفح السحابي

1. انتقل إلى صفحة المستودع المنسوخ وانقر علامة التبويب **Actions** في الأعلى
2. اعثر على **Free Cloud Browser** في الشريط الجانبي الأيسر وانقر عليه
3. انقر زر **Run workflow** على اليمين — يظهر حقلا إدخال:

| المعامل | الوصف |
|-----------|-------------|
| كلمة مرور VNC | كلمة المرور التي ستدخلها للاتصال بسطح المكتب؛ أول 8 أحرف فقط هي الفعّالة، استخدم حروفًا + أرقامًا (مثل `abc12345`)، **سجّلها**؛ كلمة مرور مؤقتة — لا تستخدم واحدة تستعملها في مكان آخر |
| مدة التشغيل | عدد الدقائق التي تبقى فيها هذه الجلسة نشطة؛ الافتراضي 300 (5 ساعات)، والحد الأقصى 350 |

4. انقر زر **Run workflow** الأخضر للتأكيد، ويبدأ تشغيل متصفحك السحابي

### الخطوة 3: احصل على رابط الوصول

1. في صفحة Actions، ادخل إلى التشغيل الذي بدأته للتو (الأعلى؛ النقطة الصفراء تعني أنه يعمل)
2. انتظر حوالي 2–4 دقائق حتى ينتهي الجهاز الافتراضي من تثبيت البرامج وإعداد النفق
3. انقر خطوة البناء لفتح السجلات، ومرر للأسفل للعثور على رابط مثل:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. انسخ هذا الرابط وافتحه في متصفح (متصفح هاتفك المدمج يعمل جيدًا)

### الخطوة 4: اتصل واستخدم

1. في صفحة noVNC التي تفتح، انقر **Connect**
2. أدخل كلمة مرور VNC التي عيّنتها في الخطوة 2
3. سترى سطح مكتب Ubuntu وChrome — استمتع 🎉

> ⌨️ طريقة الإدخال: بينيين الصينية افتراضيًا؛ اضغط **Ctrl+Space** للتبديل بين الصينية/الإنجليزية، أو انقر بزر الماوس الأيمن على سطح المكتب واختر "Switch Input Method 中/英".
> 📋 لصق الصينية: انسخ النص الصيني على هاتفك والصقه مباشرة في سطح المكتب البعيد.

### الخطوة 5: تذكّر إغلاقه

- ارجع إلى صفحة Actions، وافتح ذلك التشغيل، وانقر **Cancel run** في الأعلى يمينًا — يُدمَّر الجهاز الافتراضي ويتوقف النفق عن العمل
- ينتهي تلقائيًا أيضًا عند انقضاء مدة التشغيل المحددة، فلا حاجة للقلق بشأن استمراره للأبد

## ⚠️ ملاحظات

- **الرابط مختلف في كل مرة**: الروابط القديمة تتوقف عن العمل بمجرد انتهاء التشغيل السابق — استخدم دائمًا رابط أحدث تشغيل من السجلات
- **لا يُحفظ شيء**: بمجرد تدمير الجهاز الافتراضي، تُمسح إشارات Chrome المرجعية والملفات المُنزلة وجلسات تسجيل الدخول كلها — انقل الملفات المهمة في الوقت المناسب
- **قواعد كلمة المرور**: حروف وأرقام فقط، بحد أقصى 8 أحرف؛ كلمة مرور مؤقتة، لا تستخدم واحدة تستخدمها بانتظام
- **لا تنقر Re-run**: لبدء جلسة جديدة انقر **Run workflow** — فـ Re-run سيشغّل الشيفرة القديمة
- **اتصال بطيء/متقطع**: النفق يمر عبر Cloudflare، لذا تعتمد السرعات من البر الرئيسي الصيني على ظروف شبكتك — قابل للاستخدام، لكن لا تتوقع المعجزات

## 🛠️ تريد تعديله بنفسك؟

ملف سير العمل موجود في `.github/workflows/cloud-browser.yml` — افتحه مباشرة في واجهة GitHub الويب، وعدّله، وتدخل تغييراتك حيز التنفيذ عند الإيداع.
