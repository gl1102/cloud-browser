# ☁️ cloud-browser — 無料のクラウドブラウザ

GitHub Actions の無料 Ubuntu 仮想マシンを使って、ブラウザからリモート操作できるクラウドデスクトップを作りましょう。Chrome 内蔵。Web ページを開くだけで、インターネットに繋がるクラウド PC が使えます。使い終わったら停止するだけ。全工程無料です。

## ✨ 機能

- 🌐 Ubuntu デスクトップ + Chrome ブラウザ、ブラウザ内で直接操作
- ⌨️ fcitx5 中国語入力（ピンイン）内蔵、`Ctrl+Space` で中/英切り替え
- 📋 スマホでコピーした中国語をリモートデスクトップに直接貼り付け可能
- 🖱️ デスクトップの右クリックメニューから入力方式の切り替え・Chrome の再起動がワンクリック
- 🌐 Cloudflare トンネル経由でアクセス、パブリック IP 不要・ポート開放不要
- 🖱️ スマホ・タブレット・PC から接続可能（noVNC Web クライアント）
- ⏱️ 1 回の実行は最大約 6 時間、いつでもキャンセル可能

## 🚀 使い方（フォークしてすぐ使える）

### ステップ 1：このプロジェクトをフォーク

このページ右上の **Fork** ボタンをクリックして、プロジェクトをご自分の GitHub アカウントにコピーします。フォーク完了後は `あなたのユーザー名/cloud-browser` というリポジトリに入ります。

> 💡 なぜフォーク？GitHub Actions はご自身のアカウントのリポジトリでしか実行できないため、フォークして初めて実行権限が得られます。

### ステップ 2：クラウドブラウザを起動

1. フォーク後のリポジトリページを開き、上部の **Actions** タブをクリック
2. 左側で **Free Cloud Browser** を見つけてクリック
3. 右側の **Run workflow** ボタンをクリックすると、2 つの入力欄が表示されます：

| パラメータ | 説明 |
|------------|------|
| VNC パスワード | デスクトップ接続時に入力するパスワード。最大 8 文字まで有効、英字＋数字（例：`abc12345`）で設定し、**メモしておいてください**。使い捨てのパスワードです。普段使っているパスワードは使わないでください |
| 実行時間 | 今回のクラウドデスクトップを維持する分数。デフォルト 300（5 時間）、最大 350 |

4. 緑の **Run workflow** をクリックして確定すると、クラウドブラウザの起動が始まります

### ステップ 3：アクセスアドレスを取得

1. Actions ページで、さっきの実行（いちばん上、黄色い点が実行中）を開く
2. 仮想マシンがソフトウェアをインストールしてトンネルを構築するまで、約 2～4 分待つ
3. ビルドステップをクリックしてログを展開し、下にスクロールして次のようなアドレスを探す：

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. このアドレスをコピーしてブラウザで開く（スマホ標準ブラウザで OK）

### ステップ 4：接続して使う

1. 開いた noVNC ページで **Connect** をクリック
2. ステップ 2 で設定した VNC パスワードを入力
3. Ubuntu デスクトップと Chrome が表示されたら、使い始めましょう 🎉

> ⌨️ 入力方式：デフォルトは中国語ピンイン。**Ctrl+Space** で中/英を切り替え。デスクトップを右クリックして「入力方式を切り替え 中/英」を選ぶ方法もあります。
> 📋 中国語の貼り付け：スマホで中国語をコピーして、そのままリモートデスクトップに貼り付けてください。

### ステップ 5：使い終わったら停止

- Actions ページに戻り、その実行を開いて、右上の **Cancel run** でキャンセルすると、仮想マシンが破棄され、トンネルが無効になります
- 設定した実行時間を過ぎると自動的に終了するので、ずっと動き続ける心配はありません

## ⚠️ 注意事項

- **アドレスは毎回変わります**：古いアドレスは前回の実行終了後に無効になるので、必ず最新の実行ログのアドレスを使ってください
- **データは保存されません**：仮想マシン破棄後は、ブラウザのブックマーク・ダウンロードファイル・ログイン状態がすべて消えるので、大事なファイルは早めに取り出してください
- **パスワードのルール**：英字と数字のみ、8 文字以内。使い捨ての仮パスワードです。普段使っているパスワードは使わないでください
- **Re-run は押さない**：新規に開く場合は **Run workflow** を押してください。Re-run は古いコードで実行されます
- **接続が遅い・カクつく**：トンネルは Cloudflare 経由のため、中国本土からの速度は回線次第です。使える程度には動きます

## 🛠️ 自分でカスタマイズしたい？

ワークフローファイルは `.github/workflows/cloud-browser.yml` にあります。GitHub の Web 画面から直接開いて編集でき、コミットすれば即反映されます。
