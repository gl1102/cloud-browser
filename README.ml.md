# ☁️ cloud-browser — സൗജന്യ ക്ലൗഡ് ബ്രൗസർ

Chrome അന്തർനിർമ്മിതമായ, ബ്രൗസറിൽ നിന്ന് ആക്സസ് ചെയ്യാവുന്ന ക്ലൗഡ് ഡെസ്ക്ടോപ്പ് സജ്ജീകരിക്കാൻ GitHub Actions-ന്റെ സൗജന്യ Ubuntu വെർച്വൽ മെഷീൻ ഉപയോഗിക്കൂ. ഒരു വെബ് പേജ് തുറന്നാൽ നിങ്ങൾക്ക് ഇന്റർനെറ്റ് കണക്ഷനുള്ള ക്ലൗഡ് PC ലഭിക്കും — ജോലി കഴിഞ്ഞാൽ അത് ഓഫ് ചെയ്യൂ. പൂർണ്ണമായും സൗജന്യം.

## ✨ സവിശേഷതകൾ

- 🌐 Ubuntu ഡെസ്ക്ടോപ്പ് + Chrome ബ്രൗസർ, നിങ്ങളുടെ ബ്രൗസറിൽ തന്നെ പ്രവർത്തിപ്പിക്കാം
- ⌨️ അന്തർനിർമ്മിത fcitx5 ചൈനീസ് ഇൻപുട്ട് രീതി (Pinyin), `Ctrl+Space` ഉപയോഗിച്ച് ചൈനീസ്/ഇംഗ്ലീഷ് ഇടയിൽ മാറൂ
- 📋 ഫോണിൽ പകർത്തിയ ചൈനീസ് ടെക്സ്റ്റ് വിദൂര ഡെസ്ക്ടോപ്പിലേക്ക് നേരിട്ട് ഒട്ടിക്കാം
- 🖱️ ഇൻപുട്ട് രീതി മാറ്റാനോ Chrome ഒറ്റ ക്ലിക്കിൽ പുനരാരംഭിക്കാനോ ഉള്ള ഡെസ്ക്ടോപ്പ് വലത്-ക്ലിക്ക് മെനു
- 🌐 Cloudflare ടണൽ വഴി ആക്സസ് — പബ്ലിക് IP ആവശ്യമില്ല, പോർട്ട് ഫോർവേഡിംഗ് ആവശ്യമില്ല
- 🖱️ ഫോണിൽ നിന്നോ ടാബ്‌ലെറ്റിൽ നിന്നോ കമ്പ്യൂട്ടറിൽ നിന്നോ കണക്ട് ചെയ്യൂ (noVNC വെബ് ക്ലയന്റ്)
- ⏱️ ഓരോ സെഷനും ~6 മണിക്കൂർ വരെ നീണ്ടുനിൽക്കും, എപ്പോൾ വേണമെങ്കിലും റദ്ദാക്കാം

## 🚀 ഉപയോഗം (Fork ചെയ്ത് തുടങ്ങൂ)

### ഘട്ടം 1: ഈ പ്രോജക്റ്റ് Fork ചെയ്യൂ

ഈ പേജിന്റെ മുകളിൽ വലതുവശത്തുള്ള **Fork** ബട്ടണിൽ ക്ലിക്ക് ചെയ്ത് പ്രോജക്റ്റ് നിങ്ങളുടെ GitHub അക്കൗണ്ടിലേക്ക് പകർത്തൂ. ഫോർക്ക് ചെയ്തുകഴിഞ്ഞാൽ നിങ്ങൾ `your-username/cloud-browser` റിപ്പോസിറ്ററിയിലെത്തും.

> 💡 എന്തിനാണ് ഫോർക്ക്? GitHub Actions നിങ്ങളുടെ സ്വന്തം അക്കൗണ്ടിലെ റിപ്പോസിറ്ററികളിൽ മാത്രമേ പ്രവർത്തിക്കൂ — ഫോർക്ക് റണ്ണുകൾ ആരംഭിക്കാനുള്ള അനുമതി നൽകുന്നു.

### ഘട്ടം 2: ക്ലൗഡ് ബ്രൗസർ ആരംഭിക്കൂ

1. നിങ്ങളുടെ ഫോർക്ക് ചെയ്ത റിപ്പോസിറ്ററി പേജിൽ പോയി മുകളിലുള്ള **Actions** ടാബിൽ ക്ലിക്ക് ചെയ്യൂ
2. ഇടത് സൈഡ്ബാറിൽ **Free Cloud Browser** കണ്ടെത്തി ക്ലിക്ക് ചെയ്യൂ
3. വലതുവശത്തുള്ള **Run workflow** ബട്ടണിൽ ക്ലിക്ക് ചെയ്യൂ — രണ്ട് ഇൻപുട്ട് ഫീൽഡുകൾ തുറക്കും:

| പാരാമീറ്റർ | വിവരണം |
|-----------|-------------|
| VNC പാസ്‌വേഡ് | ഡെസ്ക്ടോപ്പിലേക്ക് കണക്ട് ചെയ്യുമ്പോൾ നിങ്ങൾ നൽകുന്ന പാസ്‌വേഡ്; ആദ്യത്തെ 8 അക്ഷരങ്ങൾ മാത്രമേ പ്രാബല്യത്തിലുള്ളൂ, അക്ഷരങ്ങൾ + അക്കങ്ങൾ ഉപയോഗിക്കൂ (ഉദാ. `abc12345`), **എഴുതിവെക്കൂ**; ഒറ്റത്തവണ പാസ്‌വേഡ് — മറ്റെവിടെയെങ്കിലും ഉപയോഗിക്കുന്ന പാസ്‌വേഡ് ഉപയോഗിക്കരുത് |
| റൺ ദൈർഘ്യം | ഈ സെഷൻ എത്ര മിനിറ്റ് നിലനിൽക്കും; സ്ഥിരസ്ഥിതി 300 (5 മണിക്കൂർ), പരമാവധി 350 |

4. സ്ഥിരീകരിക്കാൻ പച്ച **Run workflow** ബട്ടണിൽ ക്ലിക്ക് ചെയ്യൂ, നിങ്ങളുടെ ക്ലൗഡ് ബ്രൗസർ ആരംഭിക്കും

### ഘട്ടം 3: ആക്സസ് URL നേടൂ

1. Actions പേജിൽ, നിങ്ങൾ ആരംഭിച്ച റണ്ണിൽ ക്ലിക്ക് ചെയ്യൂ (ഏറ്റവും മുകളിലത്തേത്; മഞ്ഞ ഡോട്ട് എന്നാൽ അത് പ്രവർത്തിക്കുന്നുവെന്നാണ്)
2. VM സോഫ്റ്റ്‌വെയർ ഇൻസ്റ്റാൾ ചെയ്ത് ടണൽ സജ്ജീകരിക്കാൻ ഏകദേശം 2–4 മിനിറ്റ് കാത്തിരിക്കൂ
3. ലോഗുകൾ വിപുലീകരിക്കാൻ ബിൽഡ് ഘട്ടത്തിൽ ക്ലിക്ക് ചെയ്ത് താഴേക്ക് സ്ക്രോൾ ചെയ്ത് ഇതുപോലെയൊരു URL കണ്ടെത്തൂ:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. ഈ URL പകർത്തി ഒരു ബ്രൗസറിൽ തുറക്കൂ (ഫോണിന്റെ അന്തർനിർമ്മിത ബ്രൗസർ നന്നായി പ്രവർത്തിക്കും)

### ഘട്ടം 4: കണക്ട് ചെയ്ത് ഉപയോഗിക്കൂ

1. തുറക്കുന്ന noVNC പേജിൽ **Connect** ക്ലിക്ക് ചെയ്യൂ
2. ഘട്ടം 2-ൽ സജ്ജീകരിച്ച VNC പാസ്‌വേഡ് നൽകൂ
3. Ubuntu ഡെസ്ക്ടോപ്പും Chrome-ഉം കാണും — ആസ്വദിക്കൂ 🎉

> ⌨️ ഇൻപുട്ട് രീതി: സ്ഥിരസ്ഥിതി ചൈനീസ് Pinyin; ചൈനീസ്/ഇംഗ്ലീഷ് ഇടയിൽ മാറാൻ **Ctrl+Space** അമർത്തൂ, അല്ലെങ്കിൽ ഡെസ്ക്ടോപ്പിൽ വലത്-ക്ലിക്ക് ചെയ്ത് "Switch Input Method 中/英" തിരഞ്ഞെടുക്കൂ.
> 📋 ചൈനീസ് ഒട്ടിക്കൽ: ഫോണിൽ ചൈനീസ് ടെക്സ്റ്റ് പകർത്തി വിദൂര ഡെസ്ക്ടോപ്പിലേക്ക് നേരിട്ട് ഒട്ടിക്കൂ.

### ഘട്ടം 5: അത് ഓഫ് ചെയ്യാൻ മറക്കരുത്

- Actions പേജിലേക്ക് മടങ്ങി, ആ റൺ തുറന്ന് മുകളിൽ വലതുവശത്തുള്ള **Cancel run** ക്ലിക്ക് ചെയ്യൂ — VM നശിപ്പിക്കപ്പെടും, ടണൽ പ്രവർത്തനരഹിതമാകും
- നിശ്ചയിച്ച ദൈർഘ്യം കഴിഞ്ഞാൽ അത് യാന്ത്രികമായും അവസാനിക്കും, അതിനാൽ ആശങ്ക വേണ്ട

## ⚠️ കുറിപ്പുകൾ

- **URL ഓരോ തവണയും വ്യത്യസ്തമാണ്**: മുൻ റൺ അവസാനിച്ചാൽ ഉടൻ പഴയ URL-കൾ പ്രവർത്തനരഹിതമാകും — എപ്പോഴും ഏറ്റവും പുതിയ റണ്ണിന്റെ ലോഗുകളിൽ നിന്നുള്ള URL ഉപയോഗിക്കൂ
- **ഒന്നും സംരക്ഷിക്കപ്പെടുന്നില്ല**: VM നശിപ്പിക്കപ്പെട്ടാൽ, ബ്രൗസർ ബുക്ക്മാർക്കുകളും ഡൗൺലോഡ് ചെയ്ത ഫയലുകളും ലോഗിൻ സെഷനുകളും എല്ലാം മാഞ്ഞുപോകും — പ്രധാനപ്പെട്ട ഫയലുകൾ സമയത്തിന് പുറത്തേക്ക് മാറ്റൂ
- **പാസ്‌വേഡ് നിയമങ്ങൾ**: അക്ഷരങ്ങളും അക്കങ്ങളും മാത്രം, പരമാവധി 8 അക്ഷരങ്ങൾ; ഇത് ഒറ്റത്തവണ പാസ്‌വേഡാണ്, സ്ഥിരമായി ഉപയോഗിക്കുന്ന പാസ്‌വേഡ് ഉപയോഗിക്കരുത്
- **Re-run ക്ലിക്ക് ചെയ്യരുത്**: പുതിയ സെഷൻ ആരംഭിക്കാൻ **Run workflow** ക്ലിക്ക് ചെയ്യൂ — Re-run പഴയ കോഡ് പ്രവർത്തിപ്പിക്കും
- **മന്ദഗതിയിലുള്ള/ലാഗ് ആയ കണക്ഷൻ**: ടണൽ Cloudflare വഴിയാണ്, അതിനാൽ ചൈനയിൽ നിന്നുള്ള വേഗത നിങ്ങളുടെ നെറ്റ്‌വർക്ക് അവസ്ഥയെ ആശ്രയിച്ചിരിക്കും — ഉപയോഗയോഗ്യം, പക്ഷേ അത്ഭുതങ്ങൾ പ്രതീക്ഷിക്കരുത്

## 🛠️ സ്വയം മാറ്റം വരുത്തണോ?

വർക്ക്ഫ്ലോ ഫയൽ `.github/workflows/cloud-browser.yml`-ലാണ് — GitHub വെബ് UI-യിൽ തന്നെ തുറന്ന് എഡിറ്റ് ചെയ്യൂ, commit ചെയ്താൽ നിങ്ങളുടെ മാറ്റങ്ങൾ പ്രാബല്യത്തിൽ വരും.
