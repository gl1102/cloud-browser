# ☁️ cloud-browser — Безкоштовний хмарний браузер

Використовуйте безкоштовну віртуальну машину Ubuntu з GitHub Actions, щоб запустити хмарний робочий стіл, доступний з браузера, із вбудованим Chrome. Відкрийте вебсторінку — і у вас є підключений до інтернету хмарний ПК, а коли закінчите — вимкніть його. Цілком безкоштовно.

## ✨ Можливості

- 🌐 Робочий стіл Ubuntu + браузер Chrome, керування просто у вашому браузері
- ⌨️ Вбудований китайський метод введення fcitx5 (піньїнь), перемикання китайська/англійська за допомогою `Ctrl+Space`
- 📋 Китайський текст, скопійований на телефоні, можна вставити безпосередньо на віддалений робочий стіл
- 🖱️ Контекстне меню робочого столу (права кнопка миші), щоб перемкнути метод введення або перезапустити Chrome одним кліком
- 🌐 Доступ через тунель Cloudflare — без публічного IP, без пробросу портів
- 🖱️ Підключайтеся з телефона, планшета або комп'ютера (вебклієнт noVNC)
- ⏱️ Кожна сесія триває до ~6 годин, і ви можете скасувати її будь-коли

## 🚀 Як користуватися (Форк — і вперед)

### Крок 1: Зробіть форк цього проєкту

Натисніть кнопку **Fork** у верхньому правому куті цієї сторінки, щоб скопіювати проєкт у свій обліковий запис GitHub. Після форку ви опинитеся в репозиторії `your-username/cloud-browser`.

> 💡 Навіщо форк? GitHub Actions може працювати лише в репозиторіях під вашим обліковим записом — форк дає вам дозвіл запускати їх.

### Крок 2: Запустіть хмарний браузер

1. Перейдіть на сторінку свого форкнутого репозиторію та натисніть вкладку **Actions** угорі
2. Знайдіть **Free Cloud Browser** на бічній панелі ліворуч і натисніть на нього
3. Натисніть кнопку **Run workflow** праворуч — з'являться два поля введення:

| Параметр | Опис |
|-----------|-------------|
| VNC password | Пароль, який ви вводитимете для підключення до робочого столу; дієвими є лише перші 8 символів, використовуйте літери + цифри (напр. `abc12345`), **запишіть його**; одноразовий пароль — не використовуйте той, що використовуєте деінде |
| Runtime | Скільки хвилин ця сесія залишатиметься активною; за замовчуванням 300 (5 годин), максимум 350 |

4. Натисніть зелену кнопку **Run workflow** для підтвердження, і ваш хмарний браузер почне запускатися

### Крок 3: Отримайте URL доступу

1. На сторінці Actions відкрийте запуск, який ви щойно стартували (найверхній; жовта крапка означає, що він працює)
2. Зачекайте приблизно 2–4 хвилини, доки віртуальна машина завершить встановлення ПЗ і налаштування тунелю
3. Натисніть на крок збірки, щоб розгорнути логи, та прокрутіть униз, щоб знайти URL на кшталт цього:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. Скопіюйте цей URL і відкрийте його в браузері (вбудований браузер телефона цілком підійде)

### Крок 4: Підключіться та користуйтеся

1. На сторінці noVNC, що відкрилася, натисніть **Connect**
2. Введіть пароль VNC, який ви задали на кроці 2
3. Ви побачите робочий стіл Ubuntu та Chrome — насолоджуйтеся 🎉

> ⌨️ Метод введення: за замовчуванням китайський піньїнь; натисніть **Ctrl+Space**, щоб перемикатися між китайською/англійською, або клацніть правою кнопкою миші на робочому столі й оберіть «Switch Input Method 中/英».
> 📋 Вставлення китайського: скопіюйте китайський текст на телефоні та вставте його прямо на віддалений робочий стіл.

### Крок 5: Не забудьте вимкнути

- Поверніться на сторінку Actions, відкрийте той запуск і натисніть **Cancel run** у верхньому правому куті — віртуальну машину буде знищено, а тунель перестане працювати
- Він також завершиться автоматично, коли сплине заданий час, тож не хвилюйтеся, що він працюватиме вічно

## ⚠️ Примітки

- **URL щоразу інший**: старі URL перестають працювати, щойно попередній запуск завершується — завжди використовуйте URL з логів останнього запуску
- **Нічого не зберігається**: коли віртуальну машину знищено, закладки браузера, завантажені файли та сесії входу стираються — вчасно переносьте важливі файли
- **Правила пароля**: лише літери й цифри, максимум 8 символів; це одноразовий пароль, не використовуйте той, яким користуєтеся регулярно
- **Не натискайте Re-run**: щоб почати нову сесію, натисніть **Run workflow** — Re-run запустив би старий код
- **Повільне/гальмівне з'єднання**: тунель проходить через Cloudflare, тож швидкості з материкового Китаю залежать від умов вашої мережі — користуватися можна, але див не чекайте

## 🛠️ Хочете налаштувати самостійно?

Файл workflow знаходиться в `.github/workflows/cloud-browser.yml` — відкрийте його прямо у вебінтерфейсі GitHub, відредагуйте, і ваші зміни набудуть чинності після коміту.
