# ☁️ cloud-browser — مرورگر ابری رایگان

از ماشین مجازی رایگان اوبونتوی GitHub Actions برای راه‌اندازی یک دسکتاپ ابری استفاده کنید که از طریق مرورگر قابل دسترسی است و مرورگر Chrome هم داخلش هست. یک صفحه وب باز کنید و یک کامپیوتر ابری متصل به اینترنت دارید — وقتی کارتان تمام شد خاموشش کنید. کاملاً رایگان.

## ✨ ویژگی‌ها

- 🌐 دسکتاپ اوبونتو + مرورگر Chrome، دقیقاً داخل مرورگر شما اجرا می‌شود
- ⌨️ روش ورودی چینی fcitx5 داخلی (پین‌یین)، با `Ctrl+Space` بین چینی و انگلیسی جابه‌جا شوید
- 📋 متن چینی کپی‌شده در گوشی را می‌توانید مستقیماً در دسکتاپ راه دور پیست کنید
- 🖱️ منوی راست‌کلیک دسکتاپ برای جابه‌جایی روش ورودی یا ری‌استارت Chrome با یک کلیک
- 🌐 دسترسی از طریق تونل Cloudflare — بدون نیاز به IP عمومی یا فوروارد پورت
- 🖱️ از گوشی، تبلت یا کامپیوتر وصل شوید (کلاینت وب noVNC)
- ⏱️ هر نشست تا ~6 ساعت اجرا می‌شود و هر زمان می‌توانید لغو کنید

## 🚀 نحوه استفاده (فورک کنید و بروید)

### مرحله ۱: این پروژه را فورک کنید

روی دکمه **Fork** در گوشه بالای راست این صفحه کلیک کنید تا پروژه در حساب GitHub خودتان کپی شود. پس از فورک وارد مخزن `your-username/cloud-browser` می‌شوید.

> 💡 چرا فورک؟ GitHub Actions فقط روی مخازن متعلق به حساب خودتان اجرا می‌شود — فورک کردن مجوز شروع اجرا را می‌دهد.

### مرحله ۲: مرورگر ابری را شروع کنید

1. به صفحه مخزن فورک‌شده بروید و روی تب **Actions** در بالا کلیک کنید
2. در نوار کناری چپ **Free Cloud Browser** را پیدا کنید و روی آن کلیک کنید
3. روی دکمه **Run workflow** در سمت راست کلیک کنید — دو فیلد ورودی ظاهر می‌شود:

| پارامتر | توضیح |
|-----------|-------------|
| رمز عبور VNC | رمزی که برای اتصال به دسکتاپ وارد می‌کنید؛ فقط ۸ کاراکتر اول مؤثر است، از حروف + اعداد استفاده کنید (مثلاً `abc12345`)، **یادداشتش کنید**؛ رمز یک‌بارمصرف است — از رمزی که جای دیگر استفاده می‌کنید استفاده نکنید |
| مدت اجرا | این نشست چند دقیقه بالا می‌ماند؛ پیش‌فرض ۳۰۰ (۵ ساعت)، حداکثر ۳۵۰ |

4. روی دکمه سبز **Run workflow** کلیک کنید تا تأیید شود، و مرورگر ابری شروع به راه‌اندازی می‌کند

### مرحله ۳: لینک دسترسی را بگیرید

1. در صفحه Actions وارد اجرایی شوید که تازه شروع کردید (بالاترین مورد؛ نقطه زرد یعنی در حال اجراست)
2. حدود ۲ تا ۴ دقیقه صبر کنید تا ماشین مجازی نصب نرم‌افزارها و راه‌اندازی تونل را تمام کند
3. روی مرحله بیلد کلیک کنید تا لاگ‌ها باز شوند، و به پایین اسکرول کنید تا لینکی مثل این را پیدا کنید:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. این لینک را کپی کنید و در مرورگر باز کنید (مرورگر داخلی گوشی خوب کار می‌کند)

### مرحله ۴: وصل شوید و استفاده کنید

1. در صفحه noVNC که باز می‌شود روی **Connect** کلیک کنید
2. رمز عبور VNC‌ای را که در مرحله ۲ تعیین کردید وارد کنید
3. دسکتاپ اوبونتو و Chrome را می‌بینید — لذت ببرید 🎉

> ⌨️ روش ورودی: پیش‌فرض پین‌یین چینی؛ با **Ctrl+Space** بین چینی/انگلیسی جابه‌جا شوید، یا روی دسکتاپ راست‌کلیک کنید و «Switch Input Method 中/英» را انتخاب کنید.
> 📋 پیست کردن چینی: متن چینی را در گوشی کپی کنید و مستقیماً در دسکتاپ راه دور پیست کنید.

### مرحله ۵: یادتان نرود خاموشش کنید

- به صفحه Actions برگردید، آن اجرا را باز کنید و روی **Cancel run** در بالای راست کلیک کنید — ماشین مجازی نابود و تونل از کار می‌افتد
- با پایان یافتن مدت تعیین‌شده هم به‌صورت خودکار تمام می‌شود، پس نگران اجرا شدن همیشگی نباشید

## ⚠️ نکته‌ها

- **لینک هر بار فرق می‌کند**: به‌محض پایان اجرای قبلی، لینک‌های قدیمی از کار می‌افتند — همیشه از لینک آخرین اجرا در لاگ‌ها استفاده کنید
- **هیچ‌چیز ذخیره نمی‌شود**: با نابودی ماشین مجازی، بوک‌مارک‌های مرورگر، فایل‌های دانلودشده و نشست‌های ورود همه پاک می‌شوند — فایل‌های مهم را به‌موقع خارج کنید
- **قوانین رمز عبور**: فقط حروف و اعداد، حداکثر ۸ کاراکتر؛ رمز یک‌بارمصرف است، از رمزی که مرتب استفاده می‌کنید استفاده نکنید
- **روی Re-run کلیک نکنید**: برای شروع یک نشست جدید روی **Run workflow** کلیک کنید — Re-run کد قدیمی را اجرا می‌کند
- **اتصال کند/لگ‌دار**: تونل از طریق Cloudflare می‌گذرد، پس سرعت‌ها از داخل چین به وضعیت شبکه شما بستگی دارد — قابل استفاده است، اما انتظار معجزه نداشته باشید

## 🛠️ می‌خواهید خودتان دست‌کاریش کنید؟

فایل گردش‌کار در `.github/workflows/cloud-browser.yml` است — مستقیماً در رابط وب GitHub بازش کنید، ویرایش کنید و تغییراتتان با کامیت اعمال می‌شود.
