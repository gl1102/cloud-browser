# ☁️ cloud-browser — бесплатный облачный браузер

Используйте бесплатную виртуальную машину Ubuntu на GitHub Actions, чтобы получить облачный рабочий стол с доступом через браузер, со встроенным Chrome. Откройте веб-страницу — и у вас в руках облачный компьютер с интернетом; выключите, когда он больше не нужен. Полностью бесплатно.

## ✨ Возможности

- 🌐 Рабочий стол Ubuntu + браузер Chrome, управление прямо в браузере
- ⌨️ Встроенный метод ввода китайского языка fcitx5 (пиньинь), переключение китайский/английский по `Ctrl+Space`
- 📋 Китайский текст, скопированный на телефоне, можно вставить прямо в удалённый рабочий стол
- 🖱️ Контекстное меню рабочего стола: переключение метода ввода и перезапуск Chrome в один клик
- 🌐 Доступ через туннель Cloudflare — без публичного IP и проброса портов
- 🖱️ Подключение с телефона, планшета и компьютера (веб-клиент noVNC)
- ⏱️ Один запуск работает до ~6 часов, можно отменить в любой момент

## 🚀 Как пользоваться (форк — и вперёд)

### Шаг 1. Сделайте форк проекта

Нажмите кнопку **Fork** в правом верхнем углу этой страницы, чтобы скопировать проект в свою учётную запись GitHub. После форка вы окажетесь в репозитории `ваше-имя-пользователя/cloud-browser`.

> 💡 Зачем форк? GitHub Actions могут запускаться только в репозиториях вашей учётной записи — форк даёт вам право запускать workflow.

### Шаг 2. Запустите облачный браузер

1. Откройте страницу вашего форка и перейдите на вкладку **Actions** сверху
2. Слева найдите **Free Cloud Browser** и нажмите на него
3. Нажмите кнопку **Run workflow** справа — появятся два поля ввода:

| Параметр | Описание |
|----------|----------|
| VNC-пароль | Пароль для подключения к рабочему столу; учитываются не более 8 символов, используйте латинские буквы и цифры (например, `abc12345`), **запишите его**; пароль одноразовый, не используйте ваш обычный пароль |
| Длительность | Сколько минут проработает этот сеанс; по умолчанию 300 (5 часов), максимум 350 |

4. Нажмите зелёную кнопку **Run workflow** для подтверждения — облачный браузер начнёт запускаться

### Шаг 3. Получите адрес доступа

1. На странице Actions откройте только что запущенный workflow (самый верхний; жёлтая точка — выполняется)
2. Подождите примерно 2–4 минуты, пока виртуальная машина установит ПО и поднимет туннель
3. Нажмите на шаг сборки, чтобы развернуть журнал, и прокрутите вниз до адреса вроде этого:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. Скопируйте этот адрес и откройте в браузере (встроенного браузера телефона достаточно)

### Шаг 4. Подключитесь и пользуйтесь

1. На открывшейся странице noVNC нажмите **Connect**
2. Введите VNC-пароль, заданный на шаге 2
3. Увидели рабочий стол Ubuntu и Chrome — пользуйтесь 🎉

> ⌨️ Метод ввода: по умолчанию китайский пиньинь; **Ctrl+Space** переключает китайский/английский; также можно кликнуть правой кнопкой по рабочему столу и выбрать «Переключить метод ввода 中/英».
> 📋 Вставка китайского текста: скопируйте китайский текст на телефоне и вставьте его прямо в удалённый рабочий стол.

### Шаг 5. Не забудьте выключить

- Вернитесь на страницу Actions, откройте этот запуск и нажмите **Cancel run** в правом верхнем углу — виртуальная машина будет уничтожена, туннель перестанет работать
- По истечении заданного времени сеанс завершится автоматически — можно не волноваться, что он будет работать вечно

## ⚠️ Примечания

- **Адрес каждый раз новый**: старые адреса перестают работать после завершения предыдущего запуска — всегда берите адрес из журнала последнего запуска
- **Данные не сохраняются**: после уничтожения виртуальной машины закладки браузера, скачанные файлы и сессии входа полностью удаляются — вовремя переносите важные файлы
- **Правила пароля**: только латинские буквы и цифры, не более 8 символов; это временный пароль, не используйте свой обычный
- **Не нажимайте Re-run**: для нового сеанса нажмите **Run workflow** — Re-run запустит старый код
- **Медленное/тормозящее соединение**: туннель идёт через Cloudflare, скорость зависит от состояния сети — работать можно

## 🛠️ Хотите изменить под себя?

Файл workflow — `.github/workflows/cloud-browser.yml`, его можно редактировать прямо в веб-интерфейсе GitHub; изменения вступают в силу после коммита.
