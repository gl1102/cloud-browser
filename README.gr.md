# ☁️ cloud-browser — Δωρεάν Cloud Browser

Χρησιμοποιήστε τη δωρεάν εικονική μηχανή Ubuntu του GitHub Actions για να στήσετε έναν cloud υπολογιστή που προσπελάζεται από το πρόγραμμα περιήγησής σας, με ενσωματωμένο Chrome. Ανοίξτε μια ιστοσελίδα και έχετε έναν cloud υπολογιστή συνδεδεμένο στο διαδίκτυο — κλείστε τον όταν τελειώσετε. Εντελώς δωρεάν.

## ✨ Χαρακτηριστικά

- 🌐 Επιφάνεια εργασίας Ubuntu + πρόγραμμα περιήγησης Chrome, χειρισμός απευθείας μέσα από το πρόγραμμα περιήγησής σας
- ⌨️ Ενσωματωμένη μέθοδος κινεζικής εισαγωγής fcitx5 (Pinyin), εναλλαγή μεταξύ κινεζικών/αγγλικών με `Ctrl+Space`
- 📋 Κινεζικό κείμενο που αντιγράφηκε στο τηλέφωνό σας μπορεί να επικολληθεί απευθείας στην απομακρυσμένη επιφάνεια εργασίας
- 🖱️ Μενού δεξιού κλικ στην επιφάνεια εργασίας για αλλαγή της μεθόδου εισαγωγής ή επανεκκίνηση του Chrome με ένα κλικ
- 🌐 Πρόσβαση μέσω σήραγγας Cloudflare — δεν χρειάζεται δημόσια IP ούτε προώθηση θυρών
- 🖱️ Συνδεθείτε από τηλέφωνο, tablet ή υπολογιστή (web client noVNC)
- ⏱️ Κάθε συνεδρία διαρκεί έως ~6 ώρες και μπορείτε να την ακυρώσετε ανά πάσα στιγμή

## 🚀 Πώς να το χρησιμοποιήσετε (Fork και ξεκινήστε)

### Βήμα 1: Κάντε Fork αυτό το έργο

Πατήστε το κουμπί **Fork** πάνω δεξιά σε αυτή τη σελίδα για να αντιγράψετε το έργο στον δικό σας λογαριασμό GitHub. Μετά το fork, θα βρεθείτε στο αποθετήριο `your-username/cloud-browser`.

> 💡 Γιατί fork; Το GitHub Actions μπορεί να εκτελείται μόνο σε αποθετήρια του δικού σας λογαριασμού — το fork σάς δίνει την άδεια να ξεκινάτε εκτελέσεις.

### Βήμα 2: Ξεκινήστε τον Cloud Browser

1. Μεταβείτε στη σελίδα του fork σας και πατήστε την καρτέλα **Actions** στο επάνω μέρος
2. Βρείτε το **Free Cloud Browser** στην αριστερή πλαϊνή γραμμή και πατήστε το
3. Πατήστε το κουμπί **Run workflow** στα δεξιά — εμφανίζονται δύο πεδία εισαγωγής:

| Παράμετρος | Περιγραφή |
|-----------|-------------|
| Κωδικός VNC | Ο κωδικός που θα πληκτρολογήσετε για να συνδεθείτε στην επιφάνεια εργασίας· ισχύουν μόνο οι πρώτοι 8 χαρακτήρες, χρησιμοποιήστε γράμματα + αριθμούς (π.χ. `abc12345`), **σημειώστε τον**· κωδικός μιας χρήσης — μην χρησιμοποιείτε κωδικό που χρησιμοποιείτε αλλού |
| Διάρκεια εκτέλεσης | Πόσα λεπτά παραμένει ενεργή αυτή η συνεδρία· προεπιλογή 300 (5 ώρες), μέγιστο 350 |

4. Πατήστε το πράσινο κουμπί **Run workflow** για επιβεβαίωση και ο cloud browser σας ξεκινάει

### Βήμα 3: Λάβετε το URL πρόσβασης

1. Στη σελίδα Actions, μπείτε στην εκτέλεση που μόλις ξεκινήσατε (την πάνω-πάνω· η κίτρινη κουκκίδα σημαίνει ότι εκτελείται)
2. Περιμένετε περίπου 2–4 λεπτά μέχρι η VM να τελειώσει την εγκατάσταση του λογισμικού και τη δημιουργία της σήραγγας
3. Πατήστε το βήμα build για να αναπτύξετε τα αρχεία καταγραφής και κάντε κύλιση προς τα κάτω για να βρείτε ένα URL σαν αυτό:

```
https://xxx-xxx-xxx.trycloudflare.com/vnc.html
```

4. Αντιγράψτε αυτό το URL και ανοίξτε το σε ένα πρόγραμμα περιήγησης (το ενσωματωμένο πρόγραμμα περιήγησης του τηλεφώνου σας λειτουργεί μια χαρά)

### Βήμα 4: Συνδεθείτε και χρησιμοποιήστε το

1. Στη σελίδα noVNC που ανοίγει, πατήστε **Connect**
2. Πληκτρολογήστε τον κωδικό VNC που ορίσατε στο Βήμα 2
3. Θα δείτε την επιφάνεια εργασίας Ubuntu και τον Chrome — απολαύστε 🎉

> ⌨️ Μέθοδος εισαγωγής: Κινεζικά Pinyin από προεπιλογή· πατήστε **Ctrl+Space** για εναλλαγή μεταξύ κινεζικών/αγγλικών, ή κάντε δεξί κλικ στην επιφάνεια εργασίας και επιλέξτε «Switch Input Method 中/英».
> 📋 Επικόλληση κινεζικών: αντιγράψτε κινεζικό κείμενο στο τηλέφωνό σας και επικολλήστε το απευθείας στην απομακρυσμένη επιφάνεια εργασίας.

### Βήμα 5: Θυμηθείτε να το κλείσετε

- Επιστρέψτε στη σελίδα Actions, ανοίξτε αυτή την εκτέλεση και πατήστε **Cancel run** πάνω δεξιά — η VM καταστρέφεται και η σήραγγα σταματά να λειτουργεί
- Τερματίζεται επίσης αυτόματα μόλις περάσει η καθορισμένη διάρκεια, οπότε μην ανησυχείτε

## ⚠️ Σημειώσεις

- **Το URL είναι διαφορετικό κάθε φορά**: τα παλιά URL σταματούν να λειτουργούν μόλις τελειώσει η προηγούμενη εκτέλεση — χρησιμοποιείτε πάντα το URL από τα αρχεία καταγραφής της τελευταίας εκτέλεσης
- **Δεν αποθηκεύεται τίποτα**: μόλις καταστραφεί η VM, οι σελιδοδείκτες του προγράμματος περιήγησης, τα ληφθέντα αρχεία και οι συνεδρίες σύνδεσης διαγράφονται όλα — μετακινήστε έγκαιρα τα σημαντικά αρχεία
- **Κανόνες κωδικού**: μόνο γράμματα και αριθμοί, μέγιστο 8 χαρακτήρες· είναι κωδικός μιας χρήσης, μην χρησιμοποιείτε κωδικό που χρησιμοποιείτε τακτικά
- **Μην πατάτε Re-run**: για νέα συνεδρία πατήστε **Run workflow** — το Re-run θα εκτελούσε τον παλιό κώδικα
- **Αργή σύνδεση**: η σήραγγα περνάει από το Cloudflare, οπότε οι ταχύτητες από την ηπειρωτική Κίνα εξαρτώνται από τις συνθήκες του δικτύου σας — χρησιμοποιήσιμο, αλλά μην περιμένετε θαύματα

Το αρχείο workflow βρίσκεται στο `.github/workflows/cloud-browser.yml` — ανοίξτε το απευθείας στο web UI του GitHub, επεξεργαστείτε το, και οι αλλαγές σας ισχύουν με το commit.
